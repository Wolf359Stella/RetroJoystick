# Retro Joystick
This project provides code so you can bring back to life your old controller with native plug-and-play support for Linux and Windows that can read USB HID class.

This project currently includes support for:
* [Classic Joystick](<./examples/Classic/README.md>)
* [NES clones](<./examples/NES Clone/README.md>)
* [Play Station 2](<./examples/PS2/README.md>)
* [SEGA Master System](<./examples/SEGA Master System/README.md>)
* [SEGA Mega Drive](<./examples/SEGA Mega Drive/README.md>)
* [SNES](./examples/SNES/README.md)

## Requirements
 * OS (work well with USB HID as far as I know)
    * Windows >7
    * Linux Kernel >2.4 
 * Software:
    * Arduino IDE >1.6.8
 * Hardware: 
    * ATmega32u4 based Arduino (Arduino Leonardo/Micro)
